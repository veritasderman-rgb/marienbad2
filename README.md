# marienbad2

Rebrand of marienbad.com using the Ensana design system.

**Stack:** Astro 5 · React 19 · Tailwind v4 · Keystatic CMS · Vercel  
**Languages:** DE (default) · EN · CS · RU  
**Branch:** `claude/rebrand-marienbad-website-QrCzu`

## Dev

```bash
pnpm install
pnpm dev      # http://localhost:4321/de/
pnpm build
pnpm preview
```

## Design system

Colors and typography: `src/styles/global.css`  
Fonts (Branding/Latinotype): `public/fonts/`  
i18n strings: `src/i18n/ui.ts`
